* Robocopy: Comando para copiar rapidamente archivos grandes o multiples con opccion de reintento, registro en log y a 16 hilos.
   * ``` robocopy "C:\Ruta\CarpetaOrigen" "D:\Ruta\CarpetaDestino" /E /Z /ZB /MT:16 /R:3 /W:5 /TBD /V /ETA /TEE /LOG:"C:\Ruta\CarpetaOrigen\log_copia.txt" ```
